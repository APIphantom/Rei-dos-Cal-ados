# 👟 Rei dos Calçados — E-Commerce / Catálogo de Calçados

Uma plataforma de e-commerce moderna e responsiva voltada para o segmento de calçados streetwear e esportivos. O projeto foi projetado com uma estética *dark mode* urbana de alto impacto, priorizando a experiência do usuário, navegação fluida por catálogo e conversão rápida de vendas.

## 💡 Visão Geral

O **Rei dos Calçados** oferece uma vitrine digital completa para apresentação e venda de sneakers de marcas renomadas (como Nike, Adidas, Vans, Puma e Converse). A aplicação combina banners promocionais dinâmicos, produto em destaque da semana, sistema de filtros por marca e catálogo interativo.

---

## 🎨 Design e Estética

- **Estilo:** Dark Mode / Urban Streetwear
- **Cores Principais:**
  - **Amarelo / Laranja Vibrante (`#F59E0B` / `#EAB308`):** Botões de CTA, badges e destaques de preço.
  - **Preto e Cinza Escuro (`#0A0A0A` / `#121212`):** Backgrounds elegantes e áreas de exibição de produtos.
- **Destaques de Interface:**
  - Header completo com busca, carrinho, botão de login e informações de frete/parcelamento.
  - Carrossel visual de marcas parceiras.
  - Seção "Destaque da semana" com cards de produtos enriquecidos e fotos realistas.

---

## 🛠️ Tecnologias Utilizadas

- **Front-End:** React.js / Next.js
- **Estilização:** Tailwind CSS
- **Linguagem:** TypeScript
- **Backend / Banco de Dados:** Supabase / Node.js
- **Ícones:** Lucide React

---

## 📋 Funcionalidades Principais

1. **Hero Banner:** Área inicial com tagline comercial, diferenciais (frete, parcelamento, entrega rápida) e CTA.
2. **Carrossel de Marcas:** Navegação por grandes fabricantes (Nike, Adidas, Vans, Puma, Converse).
3. **Destaque da Semana:** Exibição do produto principal com descrição, preço e fotos detalhadas.
4. **Catálogo Interativo:** Filtro por marca e grid responsivo de produtos.
5. **Integração de Contato:** Botão flutuante do WhatsApp e canal de atendimento direto.
